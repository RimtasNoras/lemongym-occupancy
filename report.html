Data table
DayTimeOccupancyChange
Source: lemongym.lt club-occupancy feed, sampled on a 10-minute schedule (local launchd job plus off-machine GitHub Actions). A reading is recorded only when the fetch succeeds, so occupancy.csv contains measurements only — never a guessed value. The dashed red line is drawn at render time to fill logger outages: each missing point is modelled from the average shape of the same time of day on days that were measured, offset to meet the real readings at both ends. It is an illustration of the likely shape, not data, and is not saved anywhere.
